# Six shipped screens: comparison protocol

One Windows run builds the **tagged app** twice, not the candidate renderer with a simulated old state. The candidate supplies the same Playwright driver and fake omp to both. Desktop uses the tagged Tauri test host and WebView2 at 1280 × 860; the 390 × 844 phone uses the real paired web page in Chromium. Tailscale identity and routing are loopback fixtures. No physical phone, real model account or production data is involved.

```sh
bun scripts/ci-run.ts e2e-nightly --ref <candidate-branch> -f parity=--shipped
```

The selector is `--grep 'shipped captures'`. For one item, append its number (for example `--grep 'shipped captures #51'`). `shipped-comparison/comparison.md` lists the cases, named PNGs, and DOM measurements for that run. Open it after extracting the artifact. A missing capture or a failed case is not evidence of a pass. File a visible defect on the numbered item, linking its image, tag and run. `build.json` records the SHA that supplied the app and the separate test-driver SHA. The capture job does not modify a board or release.

For #44, Orca's [bot row](https://github.com/stablyai/orca/blob/0f56430/src/renderer/src/components/bots/BotSidebarRow.tsx) and [activity line](https://github.com/stablyai/orca/blob/0f56430/src/renderer/src/components/bots/BotRowActivityLine.tsx) use 20 + 16 px lines, 5 px vertical padding per side, 8 px icon-to-text spacing and 13 px title text. Including the two 1 px [surface borders](https://github.com/stablyai/orca/blob/0f56430/src/renderer/src/components/sidebar/workspace-card/surface/worktree-card-surface.tsx) gives 48 px; [virtual rows](https://github.com/stablyai/orca/blob/0f56430/src/renderer/src/components/bots/BotSidebarVirtualRows.tsx) likewise **estimate** 48 px and do not insert a spacer between adjacent folded entries. OMPdesk places the owner next to the name and time next to status by design; matching geometry does not require copying Orca's ordering.
